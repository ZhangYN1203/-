# 订单可靠性与连续纸打印设置：设计提案

状态：供用户审核；尚未开始实施。目标仓库：ZhangYN1203/-，基线 main e9db8a24300324acb96a2182ec6062f31d0e624c。

## 已确认的需求

用户要求优化此前识别的订单保存完整性、数据库写入、生产库存数据衔接和打印流程，并希望打印前能自由调整规格，让预览接近实际打印。用户已确认使用针式打印机与约 240×95mm 连续纸。保留 Electron、React、TypeScript、sql.js 的本地桌面架构，不引入收费云服务。

## 方案选择（待用户确认）

推荐参数化模板：调整纸张、边距、偏移、字体、行距、表格列宽、顺序与可见性，以及抬头、签字栏和页码等区块。固定纸张内自动排版，支持多模板保存，预览和打印共享页面。该方式能满足现有调拨单的调整需要，易于对连续走纸进行校准。

备选为完整拖拽式设计器：任意摆放文本、表格、图片和字段。自由度更高，但还需要设计坐标系统、吸附、重叠检查、表格跨页规则以及模板兼容。此次推荐方案不含任意绝对定位拖拽；如果用户选择备选，需要先扩展设计，而非悄悄降低功能。

## 一、订单保存

- 新建和编辑都由一次 IPC 请求提交订单与全部明细；主进程校验后在一个事务中完成。保存成功才回到列表。
- 编辑页删除明细只更新草稿；取消或离开而未保存不得删除数据库记录。对未保存修改给出离开提示。
- 失败时数据库和磁盘中的整张订单都保持保存前状态，前端保留草稿并显示可理解的错误。
- 主进程重新计算金额，不信任前端提供的 amount；数量、价格必须为有限非负值；数量允许小数，金额统一保留两位。禁止空商品明细和无效客户；保留现有可选字段的兼容性。
- 单号在事务内生成或校验，避免多个窗口提前生成相同号码；已保存单号不得因普通编辑而重置。
- 商品名称、规格、包装规格、单位、单价和客户资料作为订单快照保存。后续修改商品或客户不得改变历史订单的重打内容。
- 历史订单未保存的包装规格无法可靠还原；提议迁移后留空并标明需要核对，用户可以明确补充，不自动用当前商品规格冒充历史快照。

## 二、数据库写入与备份

- 引入同步事务辅助函数；最外层事务成功时才导出数据库一次；中途异常回滚，不写入半成品。
- 通过同目录临时文件、文件同步和原子替换保存 orders.db，保留最近一次可恢复备份。写盘失败不能向页面返回保存成功；内存状态也需恢复。
- 导入、批量调价、订单保存、库存变动及其日志都按业务操作批量提交。新增索引支持订单号、日期、客户及商品查询，避免订单列表逐条统计。
- 启动时检查数据库可读性，发现问题明确提示恢复备份；不能静默以空数据库覆盖。修正 sql-wasm.wasm 在开发和打包环境的查找。

## 三、生产和库存数据衔接

- 当前 new-modules.js 的十类 IndexedDB 记录独立于 SQLite。把它们迁入同一个 orders.db，并通过 preload 白名单 API 访问，避免生产页面继续维护另一份持久化数据。
- 为保持已有记录的 id、关联字段和现有界面兼容，第一版可在 SQLite 使用按模块和旧 id 分区的记录表保存旧记录。此为存储迁移，不把旧成品编号强行当成 products.id。
- 迁移先导出旧 IndexedDB 的完整 JSON 备份，主进程验证记录、在一个事务中导入并记录迁移版本；按实际迁移结果切换，不只按一个前端标记判断。空数据首次启动也必须正常处理。
- 原 IndexedDB 不删除。迁移失败或备份写入失败则不切换，给出明确错误和重试入口；重复启动不重复导入、不覆盖已在新数据库修改的数据。若数据库恢复到迁移前，原 IndexedDB 可重新迁移。
- 生产任务从 SQLite 的订单列表选择并保存 orderId 和单号快照；旧的手填订单号保留，能唯一匹配的才关联，无法匹配的显示未关联，不能猜测。
- 提议的关联保护规则（待用户确认）：已有生产任务关联的订单阻止删除，阻止直接修改客户、商品和数量；备注等非生产字段可修改。生产数据不随订单编辑静默改写。界面说明保护原因并引导先处理关联任务；不自动取消生产或回冲库存。
- 生产领料、成品入库、发货与对应库存日志按一次业务操作原子提交，失败不能只改库存或只写日志。现有生产成品与商品目录若未建立明确映射，分别展示，不将相似名称自动合并或重复扣减库存。

## 四、打印设置和模板

在订单打印预览页添加设置侧栏，设置变化即时更新预览，显式保存为模板后下次复用；临时调整不改变订单业务数据。

参数包括：

- 自定义纸宽、纸高（毫米），默认 240×95mm；提供连续纸与 A4 横/竖预设，纸张尺寸显式保存，不用方向与宽高重复旋转。
- 支持空白连续纸（打印完整抬头与线框）和预印套打纸（可隐藏抬头与线框，仅打印字段），避免假定用户纸张是否预印；模式与模板一起保存。
- 上下左右边距，以及横向、纵向打印偏移（毫米）。偏移用于校准，不通过偷偷缩放整个内容适配。
- 字体（默认宋体及可用中文字体回退）、字号、标题字号、单元格内边距、行距、表格边框。
- 现有八个商品列的宽度、顺序、显示/隐藏：序号、名称、规格、整箱规格、数量、单价、金额、签收意见。至少保留名称和数量。
- 是否显示商品编码、单位、单价金额、签字栏、备注、页码、每页小计、末页总计，以及单据标题文字。
- 每页最大商品行数作为上限，同时按字体实际测得的行高分页。多行商品名称、长地址、备注和最后一页合计/签字的空间都参与计算。
- 模板新建、另存、重命名、删除、恢复默认，以及模板 JSON 导出/导入（严格校验，不执行模板脚本）。已有 printPageHeight 设置需迁入默认模板。

尺寸、字体和列参数都有有限值、合理范围与总可用宽高校验。页面放不下单条完整商品行时，应明确提示并阻止该布局打印，不能截断或隐藏溢出的内容。

## 五、软件内校准面板（用户补充的重点要求）

校准必须在软件内完成，无需修改源码、配置文件或反复退出软件；用户调整时立即看到预览变化，并可直接调用系统打印对话框试打。

- 纸宽、纸高、四边边距、横向/纵向偏移使用毫米。偏移同时提供数字输入、滑块和方向微调按钮，步长可切换 0.1mm、0.5mm、1mm，明确标明正方向。纸高单独影响连续纸走纸长度。
- 字号、行距、单元格内边距、列宽、对齐、换行方式、列顺序和字段显隐均可在界面中调整；抬头、表格、页脚的间距可分别设置。
- 区分“预览缩放”和“实际打印比例”。前者仅方便屏幕查看；后者默认 100%，用户明确操作后才改变，并同时更新预览、分页、溢出检测和 PDF。禁止隐式自适应缩小。
- 提供显示/隐藏标尺、网格、纸张边界和可打印范围；显示调整后的有效宽高、页数和溢出提示。设备不可打印区域不能靠预览消除。
- “试打当前页”“打印校准页”“连续试打三页”用于检查首张位置及逐页走纸累计偏差。试打不修改订单、生产或库存数据。
- 校准页包含 100mm 标尺、十字对齐线和页起始标记。说明先调物理纸型和走纸长度，再调横纵偏移，最后调整版式；不把走纸误差全部掩盖成偏移。
- 支持按打印机和纸张/模板另存、命名和选择校准配置。切换打印机时不会无提示套用另一设备的偏移。模板负责内容版式，校准配置负责设备相关的比例、偏移和纸张参数，明确优先级并显示最终生效值。
- 提供“撤销本次调整”“恢复上次保存”“恢复默认”和“另存为”。保存前调整只是当前预览草稿，不覆盖其他模板，也不更改订单业务数据。
- 打印失败或取消后留在当前页面并保留调整；校准完成可直接保存后再次打印，无需重启。

## 六、预览与实际打印

- 同一个订单快照、模板和分页结果生成页面。所有最终尺寸使用 mm；屏幕缩放仅作用于预览外层，不改变实际排版。
- 预览显示纸张边界、可打印区和页码。等待字体加载并完成测量后才允许打印；设置或订单变化会作废旧的测量和分页，避免异步旧结果覆盖。
- 统一 Ctrl+P 与打印按钮到同一入口，移除 MutationObserver 注入设置和另一路 window.print 默认参数带来的差异。
- 在专用打印窗口使用相同页面 HTML/CSS，加载完毕后按相同物理宽高、100% 比例、统一边距调用 Electron 打印 API。打印完成、失败和取消都正确反馈，窗口与资源正确释放。
- 增加“导出 PDF”作为固定版式校样，复用打印窗口和模板，不另外实现一套模板。
- 提供含 100mm 标尺和对齐线的校准页，以及简洁的打印设置提示。预览可以尽量一致，但针式驱动的自定义纸型、不可打印边距和走纸误差需要本机校准，不能承诺所有设备完全一致。

## 七、验证与交付

- 订单：保存、取消删除、失败回滚、重新打开数据库、金额/小数数量、历史订单快照、重复单号。
- 持久化：多条写入只落盘一次；异常回滚；写盘失败；备份恢复；批量导入失败。
- 生产：空库、已有 IndexedDB、重复迁移、迁移失败重试、id 不冲突、订单关联、库存与日志原子性。
- 打印：240×95mm、A4、长商品名/地址、多页末页合计、极限列宽、隐藏列、非法模板、字体加载、打印取消、校准偏移与 PDF 页尺寸。
- 执行前端和 Electron 类型检查与构建，自动化验证可模拟的数据层和 Chromium 页面。Windows 针式打印机与驱动无法在当前云端环境中实测，交付本机校准步骤和检查清单。
- 代码在独立分支上交付可审查的 PR；不直接改 main，不自动发布应用，不引入对公网服务的依赖。
